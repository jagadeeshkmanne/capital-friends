# drive.file migration tests

TestAdapter.js holds the comparison tests used on the TEST Apps Script project
("Capital Friends v2 (TEST - drive.file migration)"). It lives outside gas-webapp/
so `clasp push` never ships it to the live app. To run again: copy it into the
TEST project's gas-webapp, push to the TEST script, run TEST_* in the editor.
Results: see ../../DRIVE-FILE-MIGRATION.md.
